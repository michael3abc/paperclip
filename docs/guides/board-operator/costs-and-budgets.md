Paperclip tracks every token spent by every agent and enforces budget limits to prevent runaway costs.

## How Cost Tracking Works

Each agent heartbeat reports cost events with:

- **Provider** — which LLM provider (Anthropic, OpenAI, etc.)
- **Model** — which model was used
- **Input tokens** — tokens sent to the model
- **Output tokens** — tokens generated by the model
- **Cost in cents** — the dollar cost of the invocation

These are aggregated per agent per month (UTC calendar month).

### Compass rate card

Compass usage is priced with the versioned card in
`server/src/services/compass-pricing.ts`. On this host, the usage-ledger service
reads `/home/michael/projects/paperclip/server/src/services/compass-pricing.ts`
from the canonical checkout. Before changing that source, run
`python3 /home/michael/services/systemd/routing/compass-usage-ledger/ops/compass-usage-report.py --check-card`.
The ledger's vendor list-price estimate is separate from an actual Compass
invoice; its rate card and the Paperclip source must agree.

Card version compass-official-2026-11-20-ttl uses the optional
usage.cacheWrite1hTokens subset of cacheWriteTokens: one-hour writes keep
input ×2 pricing, and the remaining writes use five-minute input ×1.25 pricing.
An explicit zero subset means all writes are five-minute. Without the subset,
all writes retain the conservative one-hour assumption. Input still includes
cache writes and excludes cache reads; the new counter adds no tokens.
Invalid subsets cannot close a receipt. Multiple attempts sum the subsets,
counting an unknown-TTL attempt's writes as one-hour when mixed with known TTLs.
Pricing evidence states the TTL assumption. Previously priced receipts and
historical charges remain unchanged; no backfill is performed.

OpenAI fast mode (HOM-411): a Compass OpenAI receipt whose
`pricingContext.serviceTier` is `fast` (or the older name `priority`) is priced at
exactly 2x the card's input, cache-read, cache-write and output rates, in short
and long context, and records `serviceTier: fast` with the evidence line "fast
processing at 2x standard rates". Other tiers and Anthropic fast modes stay
unpriced. The ccpocket adapter drops fast on Compass routes and does not yet
report the tier, so a receipt carries it only when a caller supplies it; the
host Codex config no longer defaults to priority. Historical receipts are not
repriced.

Failed/cancelled status does not exclude a run from accounting. If a final
receipt is lost but counters and Compass identity were saved, settlement can
price that observed usage as an estimate explicitly marked as a lower bound.
This does not recover counters that the adapter never sent: the legacy CC Pocket
adapter returns usage only from a native result, and its cancellation/error
paths do not stream usage checkpoints. The HOM-453 frozen sample's 70 cancelled
and seven failed zero-cost runs all have zero counters, unknown model/biller,
and no usage receipt ID. The server cannot reconstruct paid requests from that
empty evidence. A full fix needs request/turn-scoped incremental usage from
Bridge through adapter onUsage, including cancellation and child-call identity;
never bill a cumulative session snapshot or replay paid work to recover usage.
Coordinate the external usage-ledger card version with this version at deployment;
the source-only change does not update that managed service or its live card.

## Setting Budgets

### Company Budget

Set an overall monthly budget for the company:

```
PATCH /api/companies/{companyId}
{ "budgetMonthlyCents": 100000 }
```

### Per-Agent Budget

Set individual agent budgets from the agent configuration page or API:

```
PATCH /api/agents/{agentId}
{ "budgetMonthlyCents": 5000 }
```

## Budget Enforcement

Paperclip enforces budgets automatically:

| Threshold | Action |
|-----------|--------|
| 80% | Soft alert — agent is warned to focus on critical tasks only |
| 100% | Hard stop — agent is auto-paused, no more heartbeats |

An auto-paused agent can be resumed by increasing its budget or waiting for the next calendar month.

## Viewing Costs

### Dashboard

The dashboard shows current month spend vs budget for the company and each agent.

### Cost Breakdown API

```
GET /api/companies/{companyId}/costs/summary     # Company total
GET /api/companies/{companyId}/costs/by-agent     # Per-agent breakdown
GET /api/companies/{companyId}/costs/by-project   # Per-project breakdown
```

## Best Practices

- Set conservative budgets initially and increase as you see results
- Monitor the dashboard regularly for unexpected cost spikes
- Use per-agent budgets to limit exposure from any single agent
- Critical agents (CEO, CTO) may need higher budgets than ICs

### Compass receipts

Compass receipts optionally carry usage.cacheWrite1hTokens as a subset of cacheWriteTokens.
Price the remainder at 5m and unknown TTL at 1h with the versioned Compass card;
never reprice existing charges or backfill history. Invalid subsets stay incomplete.
Observed Compass usage without a final receipt can settle as an explicit lower bound;
missing counters stay unpriced. See docs/guides/board-operator/costs-and-budgets.md.
